Visão Geral

Este guia vai mostrar minha configuração de base padrão no Palworld para otimizar o espaço disponível, reduzindo ao mesmo tempo a chance de a IA dos Pals travar ou bugar. Funciona tanto se você tiver 20 Pals quanto 50 — o que muda é apenas a quantidade de estações de trabalho que você pode operar ao mesmo tempo. Vamos começar pelas Fundações e te guiar passo a passo até o fim.

Se você está se perguntando onde começar sua base, confira a lista dos melhores locais para construir base no Palworld 1.0.

Fundação

Coloque a Palbox no meio de uma fundação 2x2.

Vá 7 fundações para cada lado (sem contar o 2x2).

No final, vá 6 para os lados (2 extras de cada lado).

Conecte todos os lados formando um padrão circular.

Coloque fundações triangulares nas bordas para arredondar.

Preencha o resto.

Paredes

Para as paredes você pode usar qualquer material, mas o vidro ajuda a trazer luz natural.

Você vai querer subir de 3 a 5 paredes de altura. Quanto mais alto você for, menor a chance de os Pals ficarem travados em escadas e outras coisas na base. Use paredes básicas e diagonais.

Preencha o resto.

Escadas

Para as escadas, posicione-as no canto, com 2 de distância para cada lado (ignorando o triângulo). Isso vai dar bastante espaço para os Pals se movimentarem.

Você vai subir junto com as paredes. Isso também vai deixar um espaço 2x2, assim como no início das escadas.

Teto

Preencha o teto, deixando a abertura para as escadas.

Depois disso, você vai repetir os passos de paredes e escadas por até 6 andares (no máximo).

Escadas 2

Ao posicionar as escadas para o próximo andar, não esqueça de montar plataformas temporárias (mostradas em madeira).

Depois, remova a plataforma.

Posicionamento Final da Palbox

Para otimizar o espaço em cada base, remova e reposicione sua Palbox, colocando-a no andar do meio (a 4ª plataforma, como mostrado aqui).

Você também pode colocar outras coisas perto da sua Palbox, como o Baú da Guilda, a Máquina de Recuperação de Itens e o que mais quiser.

"Elevador" Aberto

Para facilitar o acesso aos diferentes andares, você pode deixar uma pequena parte aberta para usar como "elevador" usando um Pal voador.

Sala de Armazenamento

No andar de baixo é onde eu sugiro colocar seu armazenamento. Bloqueie esse espaço com uma porta para não deixar os Pals entrarem.

Coloque o máximo de baús que conseguir.

Isso tudo é para armazenamento em massa, mas você não vai querer que os Pals fiquem indo até os baús o tempo todo, aumentando o tempo de deslocamento deles. Vamos colocar baús perto das estações de trabalho para os Pals guardarem as coisas. Você vai mover os itens manualmente quando precisar.

Eventualmente você também vai colocar Máquinas de Recuperação de Itens pela base, então a organização não é tão necessária.

Posicionamento das Estações de Trabalho

Esses não são posicionamentos exatos (1 para 1); o espaço vai depender do tamanho das diferentes estruturas em cada tier.

Camas de Pal & Fontes Termais

Coloque as Camas de Pal ao redor da borda, com algumas Fontes Termais formando um semicírculo no meio. A quantidade necessária vai depender de quantos Pals você tiver. Se precisar, pode valer a pena dedicar um 2º andar só para isso.

Estações de Trabalho

Coloque suas estações de criação (crafting) no meio. Coloque baús nas extremidades. Depois, suas fornalhas, cozinhas, pedreiras, plantações e currais nos anéis externos.

Extrator de Petróleo Bruto de Alta Pressão

Se você não tiver espaço abaixo da sua base, pode abrir uma parte do piso (com cuidado) para conseguir colocar de 1 a 3 Extratores de Petróleo Bruto. Coloque pilares na borda e depois remova uma pequena parte da fundação.
